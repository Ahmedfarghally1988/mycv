## Local Development

Clone the repository:

```bash
git clone https://github.com/Ahmedfarghally1988/mycv.git
```

Navigate to the project:

```bash
cd mycv
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## Production Build

Create a production build:

```bash
npm run build
```

The static website will be generated inside:

```text
out/
```
